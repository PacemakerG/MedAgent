# MedAgent 评测方案

## 1. 总体口径

评测集共 250 个样本，按被测系统拆成三套互不混算的数据集：

| 数据集 | 数量 | 划分 | 评测对象 |
| --- | ---: | --- | --- |
| RAG | 150 | 单跳 50、多跳 50、困难检索 50 | 检索质量、答案忠实度、检索耗时 |
| 路由 | 50 | 本地 RAG 30、联网搜索 10、非医疗 10 | 最终路径与医疗科室 |
| Redis | 50 对 | 应命中 25、应拒绝复用 25 | 语义缓存判断与耗时 |

三套数据分别保存于 `backend/data/eval/rag/`、`routing/` 和 `redis/`，并分别上传到 LangSmith。每个 JSON 均包含 `metadata` 与 `samples`；构建脚本校验数量、唯一 ID、字段完整性和证据页。

RAG 问题由英文医学 PDF 的证据页反向构造，因此 150 条 Query 统一使用英文，避免人为引入跨语言变量；Query Rewrite 保持输入语言。产品入口、路由题和 Redis 缓存题仍使用中文。

## 2. RAG 评测

语料为 20 份完整医学 PDF，共 3219 页。检索时使用完整 PDF 语料，而不是只包含 gold 证据的裁剪语料。

### 指标

- `Hit@1`：首条结果命中任一 gold 证据页的问题数 / 150。
- `Recall@5`：每题前 5 条命中的 gold 证据页数 / 该题全部 gold 证据页数，再对 150 题取平均。
- `MRR`：第一条正确证据排名的倒数均值；未命中记 0。
- `答案忠实度`：有证据支持的可核对医学结论数 / 全部可核对医学结论数 × 100，满分 100。模型全量评分，另分层抽取 40 条由 Codex 复核。
- `平均检索耗时`：仅用于累计组合取舍，不扩展为其他性能指标。

不使用 `Complete@5`。

### 独立变量实验

| 版本 | 相对同一基线的单一变化 |
| --- | --- |
| B0 | 固定长度分块 + 单路向量召回 |
| B1 | B0 + 语义边界分块 |
| B2 | B0 + 父子索引 |
| B3 | B0 + OCR/文本清洗 |
| B4 | B0 + Query Rewrite |
| B5 | B0 + Elasticsearch/向量并行召回 + RRF |
| B6 | B0 + BGE Reranker |

### 累计组合与取舍

按独立实验的综合效果依次构造 C0–C6：基线、Reranker、ES/RRF、Query Rewrite、清洗、语义分块、父子索引。每加入一个模块，都与当前保留组合比较 Hit@1、Recall@5、MRR 和平均检索耗时。三个质量指标均不下降，且质量或耗时至少一项改善时才保留；父子索引另比较索引、存储和链路复杂度。

## 3. 路由评测

50 条题运行完整编译后的 LangGraph，使用真实轻量路由模型、本地 RAG、Elasticsearch 和 Tavily，不使用 mock。

- `路由准确率`：本地 RAG、联网搜索、非医疗三种最终路径判断正确的样本数 / 50。
- `科室准确率`：40 条医疗问题中主科室判断正确的样本数 / 40。

40 条医疗问题覆盖通用医疗、普外科、儿科、神经内科、感染科、耳鼻喉科、眼科、皮肤科，每科 5 条。不计算 Top3、宏平均、Precision、Recall、F1 或混淆矩阵。

## 4. Redis 语义缓存评测

每个样本是一组 `cached_question + cached_answer + probe_question + expected_hit`。25 对是含义相同但表达不同的问题，应复用答案；25 对是表面相似但疾病、症状、检查、人群或条件不同的问题，应拒绝复用。

实现链路为：医学实体抽取与归一化 → 完整实体集合 TAG 过滤 → 512 维归一化向量 → Redis Stack HNSW 余弦检索 → 相似度阈值判断。物理 Key 为 `mg:semcache:item:{uuid}`，Hash 只保存 `entities`、`embedding` 和 `answer`，并设置 TTL。同步与 SSE 链路共用同一服务。不实现意图分类、风险分类、高风险绕过或租户维度。

- `缓存命中准确率`：命中/未命中判断正确的样本数 / 50。
- `平均耗时`：对实际命中的正样本，分别统计完整 RAG 回答与缓存查询链路的平均耗时，并计算下降比例。

## 5. 复现命令

```bash
cd backend
uv run python scripts/evaluation/build_datasets.py
uv run python scripts/evaluation/upload_langsmith.py
uv run python scripts/evaluation/evaluate_rag.py --with-faithfulness
uv run python scripts/evaluation/evaluate_routing.py
uv run python scripts/evaluation/evaluate_redis_cache.py
```

正式实验要求 DeepSeek、Tavily、Redis Stack Search 和 Elasticsearch 均可用；任一真实依赖缺失时应报错，不以 mock 结果替代。
