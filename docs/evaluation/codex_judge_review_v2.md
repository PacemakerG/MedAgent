# Codex Judge 分层抽审报告

## 结论

Codex 对 180 条数据集固定分层抽取 40 条人工审核，28 条通过，通过率 **70.0%**。结构质量门禁通过不等于语义质量合格：开放域、负样本和路由标签质量稳定，但由 OCR 文本自动反向生成的部分单跳题，以及按“同科室”机械拼接的多跳题，存在明显语义残缺。

## 口径

- 抽样：固定 ID 分层抽样；覆盖 8 条单跳、8 条多跳、6 条开放域、6 条负样本和 12 条路由题。
- 评分：问题自然度、标签正确性、参考答案/证据内部一致性各 1–5 分；三项均不低于 4 分才通过。
- Judge：由 Codex 逐条阅读并打分，未调用 OpenAI API 或项目内自动 Judge 脚本。
- 边界：本次审核的是“数据集和路由标签质量”，不是模型回答质量；参考一致性是对数据集内部字段的审核，不替代医学专家复核。

## 主要问题

1. `document_seed` 中存在明显 OCR 残片，例如“第二章病”“他治疗”“关于的分泌或加强”，导致反向生成的问题缺少主体。
2. 当前多跳构造只保证同科室，没有保证两个证据存在可解释的推理关系，因此更接近“双问题机械拼接”，不是真正的 multi-hop。
3. `manual_gold_v1` 抽中样本明显优于自动文档种子，说明后续应先做 OCR 清洗和事实单元抽取，再生成 Query。
