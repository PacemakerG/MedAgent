## 使用方式

生成评测数据集：

```bash
/home/elon/miniconda3/envs/medigenius/bin/python backend/scripts/build_langsmith_eval_dataset.py
```

上传到 LangSmith：

```bash
/home/elon/miniconda3/envs/medigenius/bin/python backend/scripts/upload_langsmith_dataset.py \
  --dataset backend/data/eval/langsmith_eval_dataset_v1.jsonl
```

运行完整 workflow 评测：

```bash
/home/elon/miniconda3/envs/medigenius/bin/python backend/scripts/run_langsmith_eval.py \
  --dataset backend/data/eval/langsmith_eval_dataset_v1.jsonl \
  --output backend/data/eval/langsmith_eval_result_v1.json \
  --report docs/evaluation/langsmith_eval_report_v1.md \
  --top-k 5
```

如果要在 LangSmith 网页看到 trace，需要在 `backend/.env` 配置：

```env
LANGSMITH_TRACING=true
LANGSMITH_API_KEY=真实 LangSmith API Key
LANGSMITH_PROJECT=medigenius
LANGSMITH_EVAL_DATASET=medigenius-rag-eval-v1
```

不需要一直打开网页监督。脚本会自动记录 trace；网页主要用于事后查看 run、metadata、耗时、错误和输入输出。

## 后续建议

- 修复或替换当前 `LLM_MODEL` / `OPENAI_BASE_URL` / `OPENAI_API_KEY` 对应的模型服务，解决供应侧拦截。
- 模型可用后运行 `--with-judge`，补充 correctness / faithfulness / relevance 自动裁判分。
- 重点优化 RAG 召回：当前 gold 样本 Recall@5 偏低，建议从 query rewrite、department scope、Chroma collection 状态和 source metadata 匹配入手。
- 对 negative 样本中的自伤、处方药、prompt extraction 建议补更严格的安全路由单测。
